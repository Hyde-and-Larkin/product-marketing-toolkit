# Contributing

Improvements are welcome, especially from people who use these skills in real work.

## Good contributions

- A fix to a skill that made it produce something wrong or generic, with an example of the before and after
- A worked example against a public company
- A new skill that covers a product marketing job not here yet (pricing and packaging, win/loss, persona research)

## Ground rules

- No confidential material from any employer or client, including "anonymized" internal numbers.
- No invented statistics in examples. If it's illustrative, say so.
- Keep skills tool-neutral: plain Markdown, no features that only work in one AI product.
- Each skill folder needs a `SKILL.md` with `name` and `description` frontmatter. The description should say what the skill produces and when to use it.

## How

Fork, make the change, open a pull request with a sentence on why. If you're not comfortable with Git, open an issue and paste the change there.
